# Security reporting

Report vulnerabilities through this repository's GitHub **Security → Report a vulnerability** facility when available, or contact the maintainer privately. Do not put credentials, exploit payloads targeting production, or personal data into public issues. If private reporting is unavailable, use an established private contact before disclosing details.

Include affected version, prerequisites, minimal reproduction on a disposable WordPress site, impact and suggested mitigation. Current development and the latest published release receive fixes; older releases should be upgraded.

See [controls and gate policy](docs/security.md). Never test attacks against adventistai.lt as part of this repository's CI.
